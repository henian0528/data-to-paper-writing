# 模板

以下模板均可按选题增加字段，基本字段不减。


## 1 文献卡片（每篇文献一张）

| 字段 | 内容 |
|---|---|
| 编号 / 轮次 | L01 / R01（示意）；第一轮 / 第二轮 |
| 1 基本信息 | 作者；年份；期刊；DOI（已核实 / 待核实） |
| 2 研究区与气候区 | 城市或区域；气候区 |
| 3 数据与方法 | 数据（来源、时相）；尺度；模型；参照 / 背景定义 |
| 4 核心结论 | ①变量、方向、条件、关键数字；②……；③…… |
| 5 适用条件 | 季节；昼夜；尺度；背景类型 |
| 6 与本研究的关系 | 可比变量；相同条件；不同条件；比较数字还是只比较方向 |
| 7 来源证据 | ①页码 / 原句；②……；③……（未找到时写“未找到”） |
| 状态 | 已核实 / 待核实 / 仅摘要 / 转引 / 仅图表；用户是否已抽查 |
