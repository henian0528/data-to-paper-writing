# data-to-paper-writing：从数据到结论到成稿的论文写作工作流

一个给 AI 智能体（Claude Code、Cursor 等支持 skill 的工具）用的写作 skill，帮你把已有的研究结果写成中文期刊论文。

它解决的核心问题是：AI 写论文常常跳过“解释”这一步，只会复述图表数字、到处设防，或者夸大发现。本 skill 要求先下判断、再动笔：

1. **文献预期表**：看结果之前，先从文献整理出“一般认为是怎样”，并冻结。
2. **发现清单**：把结果与预期逐条对照（一致、相反、未报道），每个发现写主张、证据、机制、另一种解释和把握程度（强、中、弱）。等级决定它进摘要、讨论还是局限。
3. **固定章节写法**：数据与方法、结果、讨论、结论、引言、摘要各有规定的结构、措辞规则和常见毛病，每节只以发现清单为输入。
4. **独立审稿自查**：写和审分开，问题分“必须改”（每轮最多 5 条）和“建议改”两档。

流程中有多个停点（确认文献名单、抽查文献卡片、冻结预期表、定发现等级、批准各章），关键判断都由作者本人拍板。

## 目录结构

```
data-to-paper-writing/
├── SKILL.md            总入口：原则、11 步顺序、停点、从中途开始
└── references/         文献、发现清单、各章写法、审稿清单、材料说明、模板
```

## 安装

把 `data-to-paper-writing/` 整个文件夹复制到你所用工具的 skills 目录（例如 Claude Code 的 `~/.claude/skills/`）。

## 使用

对智能体说明你要写全文或其中某一节，并指定一个项目文件夹（如 `<项目>/writing/`），过程产物与进度都保存在里面，可随时中断续写。也可以只用来建文献预期表、整理发现清单，或做投稿前自查。

默认面向中文稿件；投英文期刊时流程不变，措辞规则换成英文对应写法，字数与关键词数以期刊要求为准。

文中示例均为虚构，仅示意格式。
